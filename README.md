# 🧩 Problem-Solving Workflow

Every problem is approached through a structured engineering process.

```text
┌───────────────────────┐
│   Understand Problem  │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│   Analyze Constraints │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│   Identify Pattern    │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│   Design Approach     │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│ Analyze Time & Space  │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│      Implement        │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│    Test Edge Cases    │
└───────────┬───────────┘
            ▼
┌───────────────────────┐
│       Optimize        │
└───────────┬───────────┘
            ▼
       Accepted ✅
```

The goal is not simply to reach an accepted solution.

The focus is on writing solutions that are:

**Correct • Efficient • Readable • Maintainable • Reusable**
